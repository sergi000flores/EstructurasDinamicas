# EstructurasDinamicas (C# / .NET 8)

Aplicación de consola con:
1. Lista doblemente enlazada genérica con nodos dinámicos (`Estructuras/`).
2. Uso de `Stack<T>`, `Queue<T>`, `List<T>` y `LinkedList<T>` + `PilaDinamica<T>` y `ColaDinamica<T>` propias.
3. Comparación estático vs. dinámico (memoria).

Entregable: `Documento_Comparativo_Estatico_vs_Dinamico.docx`

## Ejecutar
- Visual Studio 2022: abrir `EstructurasDinamicas.sln` y presionar F5.
- Terminal: `dotnet run --project EstructurasDinamicas`

Requiere .NET SDK 8 o superior (si usas otra versión, cambia `TargetFramework` en el .csproj).
